# DBC Guard: release plan

1. Inspect pinned Meteora SDK account layouts and fee calculations; implement bounded server-side Solana RPC reads with account owner/discriminator validation.
2. Implement deterministic assessment with evidence, explicit unknown coverage, mint authorities and extensions, fees, LP distribution/locking, curve structure and migration status.
3. Build responsive pool inspection interface, clearly synthetic demo, shareable input URL, JSON reports and PNG evidence card.
4. Test scoring and malformed upstream data; typecheck and production build. Verify live RPC reads where network allows.
5. Supply methodology, environment example, Docker deployment and hackathon submission instructions. Public deployment requires account/hosting authorization.

Completion means a runnable product with successful tests/build and documented live verification results, not a claim that any pool is safe.
